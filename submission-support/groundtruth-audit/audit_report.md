1. **Pie chart slice counts** — 41/52 (79%) never state total number of slices. Annotators should add this.

3. **Bar chart color-to-bar mapping** — 76/99 (77%) have only partial bar descriptions. Color assignments often missing.
4. **fig_083** — Worst bar chart (5 issues): missing axis details, bar descriptions, legend, grouped structure.
5. **fig_115** — Worst line plot (6 issues): missing both axis labels, no markers/styles, vague purpose.
6. **fig_250** — Worst pie chart (5 issues): no slice count, few labels, no placement/emphasis/ordering.

### Systematic Gaps (Not Per-Figure)

- **Error bars / confidence intervals** — never mentioned in any bar chart annotation
- **Truncated axes** — never flagged even when y-axis starts at 65 or 80
- **Line marker shapes** — omitted in ~15% of line plot annotations
- **Subplot handling** — 37 line plots appear to have subplots but don't describe them as such
- **Percentage sums** — never verified in pie chart annotations

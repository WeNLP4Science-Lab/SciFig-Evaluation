\vspace{2pt}
\begin{codebox}[title={\scriptsize C3: Compositional Chain-of-Thought (CCoT) prefix}]
First, describe the visual structure of this figure: identify the
chart type, axes, data series, labels, colors, and any notable
patterns. Let's think step by step.

After your reasoning, write your final description on a new line
starting with "DESCRIPTION:" --- only the text after DESCRIPTION:
will be used for evaluation.
\end{codebox}
\vspace{2pt}
\begin{codebox}[title={\scriptsize Atomic MQM judge prompt (key sections)}]
You are an expert evaluator assessing the quality of a
machine-generated scientific figure description using an atomic
checklist approach. You are given the FIGURE IMAGE, an ATOM
CHECKLIST, the full REFERENCE DESCRIPTION, and the MACHINE
DESCRIPTION. The IMAGE is the primary source of truth.

Tolerance: numerical +/-3 percentage points; colour synonyms
accepted (blue/cyan/teal, red/crimson); semantic equivalence.

Step 1: Accuracy check (image + atoms)
Step 2: Completeness check (atoms)
Step 3: Hallucination check (atoms + image)
Step 4: Clarity check (reference)

Severity: atom severity caps error severity.
  Critical/Important atom + complete miss -> Major
  Critical/Important atom + partial       -> Minor
  Minor atom, any degree of error         -> Minor

Output: {"errors": [{"category", "sub_type", "severity",
  "text_span", "evidence", "atom_id"}]}
\end{codebox}
\end{minipage}\hfill

\vspace{6pt}
\noindent\textbf{Normalised MQM score:}
\[
\mathrm{MQM} = \max\!\left(0,\; 100 - \frac{\sum_{i} w_i}{N_{\mathrm{atoms}} \times 5.0} \times 100\right)
\]
where $N_{\mathrm{atoms}}$ is the atom count for the figure and $5.0$ is the maximum per-atom penalty (Accuracy/Major). Hallucination and clarity errors add to the numerator without appearing in the denominator, so scores can reach zero but not go negative.

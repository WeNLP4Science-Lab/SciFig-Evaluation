\section{Generation Prompts}
\label{app:gen-prompts}

All generation prompts follow the same structure: role instruction, objective, content requirements, and constraints. Below we reproduce the English prompts for each chart type (left) alongside the German translations (right). Bulgarian and Chinese translations follow the same pattern.

\begin{figure}[H]
\centering
\begin{minipage}[t]{0.48\textwidth}
\begin{codebox}[title={EN: Line plot prompt}]
You are an annotator tasked with describing
scientific line plots in a structured but
natural paragraph format. Your goal is to
clearly describe what is shown, without making
inferences. Include: overall purpose, x-axis
(label, scale, range, units), y-axis (same),
each line (color, marker, style, values at
start/end, peaks/declines). Avoid interpreting
causes. Write in a single paragraph.
\end{codebox}
\end{minipage}\hfill
\begin{minipage}[t]{0.48\textwidth}
\begin{codebox}[title={DE: Liniendiagramm-Prompt}]
Sie sind ein Annotator, dessen Aufgabe es ist,
wissenschaftliche Liniendiagramme zu beschreiben.
Ihr Ziel ist es, das Dargestellte objektiv zu
beschreiben. Enthalten Sie: Gesamtzweck,
x-Achse (Beschriftung, Skala, Bereich),
y-Achse (ebenso), jede Linie (Farbe, Marker,
Stil, Werte). Vermeiden Sie Interpretationen.
Schreiben Sie in einem Absatz.
\end{codebox}
\end{minipage}

\vspace{4pt}
\begin{minipage}[t]{0.48\textwidth}
\begin{codebox}[title={EN: Bar chart prompt}]
You are an annotator tasked with describing
scientific bar charts. Include: purpose, axes
(category axis, value axis with label/scale/
range/units), each bar (label, color, value),
grouped/stacked structure, sorting, visual
emphasis. Avoid comparisons. Single paragraph.
\end{codebox}
\end{minipage}\hfill
\begin{minipage}[t]{0.48\textwidth}
\begin{codebox}[title={DE: Balkendiagramm-Prompt}]
Sie sind ein Annotator fuer wissenschaftliche
Balkendiagramme. Enthalten Sie: Zweck, Achsen
(Kategorieachse, Werteachse mit Beschriftung/
Skala/Bereich), jeden Balken (Beschriftung,
Farbe, Wert), Gruppierung/Stapelung,
Sortierung. Vermeiden Sie Vergleiche.
Ein zusammenhaengender Absatz.
\end{codebox}
\end{minipage}

\vspace{4pt}
\begin{minipage}[t]{0.48\textwidth}
\begin{codebox}[title={EN: Pie chart prompt}]
You are an annotator for scientific pie charts.
Include: purpose, total slices, each slice
(label, color, percentage), legend presence,
percentage labels, visual emphasis (exploded/
offset slices), ordering. Single paragraph.
\end{codebox}
\end{minipage}\hfill
\begin{minipage}[t]{0.48\textwidth}
\begin{codebox}[title={BG: Prompt za krugovi diagrami}]
Vie ste anotator za nauchni krugovi diagrami.
Vklyuchete: tsel, broi sektori, vseki sektor
(etiket, tsvetove, protsent), legenda, vizualno
podchertavane. Edin paragraf. (Full Cyrillic
version in the codebase.)
\end{codebox}
\end{minipage}

{\scriptsize
\begin{codebox}[title={\scriptsize Atomic MQM judge prompt (key sections)}]
You are an expert evaluator using an atomic
checklist. Given: IMAGE, ATOM CHECKLIST,
REFERENCE, MACHINE DESCRIPTION.
IMAGE is primary source of truth.
Tolerance: +/-3pp numerical, colour synonyms.
Step 1: Accuracy (image + atoms)
Step 2: Completeness (atoms)
Step 3: Hallucination (atoms + image)
Step 4: Clarity (reference)
Severity: atom severity caps error severity.
 Crit/Imp + complete miss -> Major
 Crit/Imp + partial       -> Minor
 Minor atom               -> Minor
Output: {"errors":[{"category","sub_type",
 "severity","text_span","evidence","atom_id"}]}
\end{codebox}
}

$\mathrm{MQM} = \max\!\bigl(0,\, 100 - \frac{\sum w_i}{N_a \times 5}\times 100\bigr)$\\
$N_a$ = atom count. Full prompt: \texttt{atomic\_mqm/judge\_prompt.txt}.
